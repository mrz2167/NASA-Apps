# seed/queries — готовый поиск IRSA для полей сайта

Каждый файл — ответ IRSA TAP «какие снимки SPHEREx накрывают эту точку» (тот же формат, что `cache/queries/`).
По нему сервер собирает поле из открытого бакета AWS без IRSA: кейсы, «Try» и «Surprise me» открываются,
даже когда поиск IRSA лежит (как в ноябре 2026). Порядок в `data.find_images`: кэш → seed → IRSA.

Обновить (когда IRSA работает; заодно подтянутся новые проходы SPHEREx): `python make_seed.py`
